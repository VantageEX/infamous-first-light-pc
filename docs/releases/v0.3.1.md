# v0.3.1 — freeze fix

> **You need your own copy of the game**, dumped from your own PS4 (CUSA00897, base game 1.00 is the tested one). This download has no game files.

## What's new

- **Fixed: the game could freeze for good after a few minutes on renderer v2.** Two parts of the renderer waited for each other (the texture cache and the GPU command processor). 20 minutes of testing without a single freeze, where it used to freeze after 4–6 minutes.
- Renderer v2 uses about one CPU core less: a worker thread spun while waiting instead of sleeping. This helps most on CPUs with 4–6 cores and on laptops.

## Updating

Unzip into a new folder and copy the `data` folder from the old version next to the new **inFAMOUS First Light.exe** to keep your saves, settings and shader caches.

## How to play

1. Unzip `inFAMOUS-First-Light-PC-v0.3.1.zip` anywhere (not in Program Files).
2. Start **inFAMOUS First Light.exe** and pick your game folder (the one with `eboot.bin` and `sce_sys`).
3. Press **Play**. F10 shows the FPS overlay, Insert (or R3 + L2) opens the in-game menu.

Windows 10/11 64-bit, a Vulkan 1.3 GPU and a CPU with AVX are needed. If Windows SmartScreen warns about an unknown app, choose *More info → Run anyway* (the build is not signed).

## Known issues

- The classic (fallback) renderer flashes yellow for a moment while a save loads, and its first start takes about 3 minutes. Renderer v2, the default, has neither.
- Reading GPU data back still costs frame rate (work in progress).
- Some lights pulse in the boat cutscene.
- If the game still freezes, wait about 15 s before closing it, then send the report: the log records what the game was waiting for.

Feedback is welcome in the [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): your CPU, GPU, FPS and what you saw.

# v0.3.1 — исправление зависания

> **Нужна ваша собственная копия игры**, снятая с вашей PS4 (проверена CUSA00897, базовая версия 1.00). В архиве нет файлов игры.

## Что нового

- **Исправлено: на рендере v2 игра могла намертво зависнуть через несколько минут.** Две части рендера ждали друг друга (кэш текстур и командный процессор видеокарты). В тесте 20 минут без единого зависания, а раньше игра вставала через 4–6 минут.
- Рендер v2 расходует примерно на одно ядро процессора меньше: служебный поток при ожидании крутился вхолостую, а не спал. Сильнее всего это поможет на процессорах с 4–6 ядрами и на ноутбуках.

## Обновление

Распакуйте в новую папку и скопируйте папку `data` из старой версии рядом с новым **inFAMOUS First Light.exe**, чтобы сохранить сейвы, настройки и кэш шейдеров.

## Как играть

1. Распакуйте `inFAMOUS-First-Light-PC-v0.3.1.zip` куда угодно (не в Program Files).
2. Запустите **inFAMOUS First Light.exe** и выберите папку с игрой (в ней `eboot.bin` и `sce_sys`).
3. Нажмите **«Играть»**. F10 — счётчик FPS, Insert (или R3 + L2) — меню в игре.

Нужны Windows 10/11 64-бит, видеокарта с Vulkan 1.3 и процессор с AVX. Если Windows SmartScreen предупредит о неизвестном приложении, нажмите *«Подробнее» → «Выполнить в любом случае»* (сборка не подписана).

## Известные проблемы

- На обычном (запасном) рендере при загрузке сохранения на мгновение мелькает жёлтый, а первый запуск занимает около 3 минут. На рендере v2, который стоит по умолчанию, такого нет.
- Чтение данных с видеокарты всё ещё стоит FPS (в работе).
- В катсцене с лодкой мигают некоторые огни.
- Если игра всё-таки зависнет, подождите секунд 15, прежде чем закрывать, и пришлите отчёт: в журнале записывается, чего ждала игра.

Отзывы ждём в [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): ваш процессор, видеокарта, FPS и что вы увидели.
