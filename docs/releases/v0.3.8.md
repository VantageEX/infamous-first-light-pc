# v0.3.8

## What's new

- **Input display** ([#15](https://github.com/VantageEX/infamous-first-light-pc/pull/15), by [eslamira](https://github.com/eslamira)): **F9** shows a small keyboard and mouse on screen that light up with the keys and buttons you hold, for recordings, streams and tutorials. Other keys held (Enter, the arrows...) show as chips under it. Insert menu → Controls → Input display: on/off, position (the corners, the middle of each edge), size and background opacity. In the bottom left corner it moves up above the touchpad box while Ctrl shows it. Off by default.
- **Fixed: renderer v2 closed right before the game started on some copies of CUSA00897 01.00** ([#14](https://github.com/VantageEX/infamous-first-light-pc/issues/14)). There are two builds of this version of the game; on the older one (built with SDK 1.60) a check meant for inFAMOUS Second Son read a part of the game's code that is not there. If your copy is that build, please tell us in #14 how far it gets now.

# v0.3.8

## Что нового

- **Отображение нажатий** ([#15](https://github.com/VantageEX/infamous-first-light-pc/pull/15), автор — [eslamira](https://github.com/eslamira)): **F9** показывает на экране небольшие клавиатуру и мышь, на которых подсвечиваются нажатые клавиши и кнопки, — для записи, стримов и обучающих видео. Остальные зажатые клавиши (Enter, стрелки...) появляются плашками под ними. Меню Insert → Управление → «Отображение нажатий»: вкл/выкл, положение (углы, середина каждого края), размер и прозрачность фона. В левом нижнем углу оно поднимается над окошком тачпада, пока зажат Ctrl. По умолчанию выключено.
- **Исправлено: на некоторых копиях CUSA00897 01.00 рендер v2 закрывался перед самым запуском игры** ([#14](https://github.com/VantageEX/infamous-first-light-pc/issues/14)). У этой версии игры есть две сборки; на более старой (собранной с SDK 1.60) проверка, рассчитанная на inFAMOUS Second Son, читала часть кода игры, которой там нет. Если у вас такая копия, расскажите в #14, докуда игра доходит теперь.
