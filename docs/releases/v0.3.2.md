# v0.3.2 — new in-game interface, updates from the launcher

> **You need your own copy of the game**, dumped from your own PS4 (CUSA00897, base game 1.00 is the tested one). This download has no game files.

## What's new

- **A new in-game interface in the launcher's look.** The Insert menu, the save and load screens, their questions, "Game saved", the graffiti guide, text entry, the shader loading screen and the FPS overlay now look like the launcher: frosted glass panels over the blurred game, sections with icons, the launcher's switches, lists and sliders, white and frosted pill buttons. Save cards show the mission and its progress first.
- **A Continue card in the launcher:** the mission and story progress of your newest save, when you saved, and how many saves you have.
- **The launcher updates itself.** When it starts, it checks GitHub for a newer release. If there is one, a card at the top right offers **Update**: the package is downloaded, checked against the SHA-256 GitHub publishes, and installed; the launcher restarts into the new version. Your saves, settings and shader caches (the `data` folder) stay as they are. If replacing a file fails, the previous version is put back.
- The check is one request to GitHub's release list; nothing about you or your PC is sent.
- A launcher in a folder it cannot write to (such as Program Files) only shows the release page.

This is the first version that can update itself: from v0.3.1 or older, download it once by hand. Later versions will install from the launcher.

## Updating from an older version

Unzip into a new folder and copy the `data` folder from the old version next to the new **inFAMOUS First Light.exe** to keep your saves, settings and shader caches.

## How to play

1. Unzip `inFAMOUS-First-Light-PC-v0.3.2.zip` anywhere you can write to (not in Program Files).
2. Start **inFAMOUS First Light.exe** and pick your game folder (the one with `eboot.bin` and `sce_sys`).
3. Press **Play**. F10 shows the FPS overlay, Insert (or R3 + L2) opens the in-game menu.

Windows 10/11 64-bit, a Vulkan 1.3 GPU and a CPU with AVX are needed. If Windows SmartScreen warns about an unknown app, choose *More info → Run anyway* (the build is not signed).

## Known issues

- The classic (fallback) renderer flashes yellow for a moment while a save loads, and its first start takes about 3 minutes. Renderer v2, the default, has neither.
- Reading GPU data back still costs frame rate (work in progress).
- Some lights pulse in the boat cutscene.
- If the game freezes, wait about 15 s before closing it, then send the report: the log records what the game was waiting for.

Feedback is welcome in the [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): your CPU, GPU, FPS and what you saw.

# v0.3.2 — новый интерфейс в игре, обновления из лаунчера

> **Нужна ваша собственная копия игры**, снятая с вашей PS4 (проверена CUSA00897, базовая версия 1.00). В архиве нет файлов игры.

## Что нового

- **Новый интерфейс в игре в стиле лаунчера.** Меню по Insert, экраны сохранения и загрузки, вопросы к ним, «Игра сохранена», подсказка про граффити, ввод текста, экран загрузки шейдеров и счётчик FPS теперь выглядят как лаунчер: панели из матового стекла поверх размытой игры, разделы с иконками, переключатели, списки и ползунки как в лаунчере, белые и матовые кнопки. В карточках сохранений крупно показаны миссия и прогресс.
- **Карточка «Продолжить» в лаунчере:** миссия и прогресс последнего сохранения, когда вы сохранялись и сколько у вас сохранений.
- **Лаунчер обновляется сам.** При запуске он проверяет на GitHub, не вышла ли новая версия. Если вышла, справа вверху появляется карточка с кнопкой **«Обновить»**: архив скачивается, сверяется с контрольной суммой SHA-256 с GitHub и устанавливается, лаунчер перезапускается уже в новой версии. Сохранения, настройки и кэш шейдеров (папка `data`) остаются на месте. Если заменить какой-то файл не удалось, возвращается прежняя версия.
- Проверка — это один запрос к списку релизов на GitHub; никаких данных о вас или вашем ПК не отправляется.
- Если лаунчер лежит в папке, куда нельзя писать (например, Program Files), он только откроет страницу релиза.

Это первая версия, которая умеет обновляться сама: с v0.3.1 и старше скачайте её один раз вручную. Следующие версии будут ставиться из лаунчера.

## Обновление со старой версии

Распакуйте в новую папку и скопируйте папку `data` из старой версии рядом с новым **inFAMOUS First Light.exe**, чтобы сохранить сейвы, настройки и кэш шейдеров.

## Как играть

1. Распакуйте `inFAMOUS-First-Light-PC-v0.3.2.zip` в любую папку, куда можно писать (не в Program Files).
2. Запустите **inFAMOUS First Light.exe** и выберите папку с игрой (в ней `eboot.bin` и `sce_sys`).
3. Нажмите **«Играть»**. F10 — счётчик FPS, Insert (или R3 + L2) — меню в игре.

Нужны Windows 10/11 64-бит, видеокарта с Vulkan 1.3 и процессор с AVX. Если Windows SmartScreen предупредит о неизвестном приложении, нажмите *«Подробнее» → «Выполнить в любом случае»* (сборка не подписана).

## Известные проблемы

- На обычном (запасном) рендере при загрузке сохранения на мгновение мелькает жёлтый, а первый запуск занимает около 3 минут. На рендере v2, который стоит по умолчанию, такого нет.
- Чтение данных с видеокарты всё ещё стоит FPS (в работе).
- В катсцене с лодкой мигают некоторые огни.
- Если игра зависнет, подождите секунд 15, прежде чем закрывать, и пришлите отчёт: в журнале записывается, чего ждала игра.

Отзывы ждём в [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): ваш процессор, видеокарта, FPS и что вы увидели.
