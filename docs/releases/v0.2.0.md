# v0.2.0 — renderer v2, about twice the frame rate

> **You need your own copy of the game**, dumped from your own PS4 (CUSA00897, base game 1.00 is the tested one). This download has no game files.

## What's new

- **Renderer v2 is the default**: about 35–45 FPS in the city instead of 15–25 (Ryzen + RTX 4070 SUPER). The classic renderer stays in the launcher's display settings as a fallback.
- **The first start compiles the game's shaders** (about 1.5–2 minutes, with a progress bar). Graphics pipelines are cached as you play, so stutters fade after the first sessions.
- **Fixed:** yellow flickering on lamps and buildings.
- The shader loading screen is in English and Russian.
- Newer core from iss_pc (HayatoG), with renderer v2 by Castlesea.
- If the game freezes, the log now records what it was waiting for (wait about 15 s before closing it, then send the log).

## Updating from v0.1.0

Unzip into a new folder. To keep your saves and settings, copy the `data` folder from the old version next to the new **inFAMOUS First Light.exe**.

## How to play

1. Unzip `inFAMOUS-First-Light-PC-v0.2.0.zip` anywhere (not in Program Files).
2. Start **inFAMOUS First Light.exe** and pick your game folder (the one with `eboot.bin` and `sce_sys`).
3. Press **Play**. F10 shows the FPS overlay, Insert (or R3 + L2) opens the in-game menu.

Windows 10/11 64-bit, a Vulkan 1.3 GPU and a CPU with AVX are needed. If Windows SmartScreen warns about an unknown app, choose *More info → Run anyway* (the build is not signed).

## Known issues

- Renderer v2 is new: one freeze was seen in testing. If you get one, please report it with the log.
- Reading GPU data back still costs frame rate (work in progress).
- Some lights pulse in the boat cutscene.

Feedback is welcome in the [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): your CPU, GPU, FPS and what you saw.

# v0.2.0 — рендер v2, FPS примерно вдвое выше

> **Нужна ваша собственная копия игры**, снятая с вашей PS4 (проверена CUSA00897, базовая версия 1.00). В архиве нет файлов игры.

## Что нового

- **Рендер v2 по умолчанию**: около 35–45 FPS в городе вместо 15–25 (Ryzen + RTX 4070 SUPER). Обычный рендер остался в настройках экрана лаунчера как запасной.
- **Первый запуск компилирует шейдеры игры** (примерно 1,5–2 минуты, с полосой прогресса). Графические пайплайны сохраняются в кэш во время игры, поэтому подлагивания уходят после первых сессий.
- **Исправлено:** жёлтое мерцание фонарей и зданий.
- Экран загрузки шейдеров на русском и английском.
- Обновлённое ядро из iss_pc (HayatoG), рендер v2 от Castlesea.
- Если игра зависнет, в журнал теперь записывается, чего она ждала (подождите секунд 15, прежде чем закрывать, и пришлите журнал).

## Обновление с v0.1.0

Распакуйте в новую папку. Чтобы сохранить сейвы и настройки, скопируйте папку `data` из старой версии рядом с новым **inFAMOUS First Light.exe**.

## Как играть

1. Распакуйте `inFAMOUS-First-Light-PC-v0.2.0.zip` куда угодно (не в Program Files).
2. Запустите **inFAMOUS First Light.exe** и выберите папку с игрой (в ней `eboot.bin` и `sce_sys`).
3. Нажмите **«Играть»**. F10 — счётчик FPS, Insert (или R3 + L2) — меню в игре.

Нужны Windows 10/11 64-бит, видеокарта с Vulkan 1.3 и процессор с AVX. Если Windows SmartScreen предупредит о неизвестном приложении, нажмите *«Подробнее» → «Выполнить в любом случае»* (сборка не подписана).

## Известные проблемы

- Рендер v2 новый: в тестах было одно зависание. Если поймаете, пришлите отчёт с журналом.
- Чтение данных с видеокарты всё ещё стоит FPS (в работе).
- В катсцене с лодкой мигают некоторые огни.

Отзывы ждём в [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): ваш процессор, видеокарта, FPS и что вы увидели.
