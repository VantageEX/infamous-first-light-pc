# v0.3.3

## What's new

- **New: renderer v3 (experimental).** A third renderer, picked in the launcher under Display → Renderer → "v3 — experimental": **axylpup**'s multithreaded Second Son build of shadPS4 ([second-son-v1.1.1](https://github.com/axylpup/shadPS4/tree/second-son)), running on this port's core. While it is picked the launcher shows a notice across its window: **it is an early version — expect artifacts, crashes and frame drops, no promises.** If something is wrong, switch back to renderer v2 (still the default).
  - On a Ryzen 7 5700X + RTX 4070 SUPER at 1080p: 35–45 FPS in the streets (as renderer v2), 60–100 high up — the frame rate is no longer held to steps of 60 Hz; the launcher's FPS limit and VSync apply.
  - Far fewer stutters than in its first builds: the big 50–100 ms hitches (thousands of memory faults a frame in the particle and file streaming paths) are gone.
  - The first start prepares the game's shaders (about two minutes) with a progress screen, as renderer v2 does; later starts skip it.
  - Not there yet: FSR 1 / RCAS do not apply to it, and it is Windows only.
- **Fixed: the launcher window ran off the screen** on smaller or high-DPI screens (handhelds such as the OneXPlayer X1 at 200% scaling): the settings at the bottom right were out of sight. The launcher now fits its window to the screen and centres it.
- **Launcher fonts:** Open Sans and Fluent UI System Icons where Segoe UI is missing.

# v0.3.3

## Что нового

- **Новое: рендер v3 (экспериментальный).** Третий рендер, выбирается в лаунчере: Экран → Рендер → «v3 — экспериментальный». Это многопоточная сборка shadPS4 для Second Son от **axylpup** ([second-son-v1.1.1](https://github.com/axylpup/shadPS4/tree/second-son)), работающая на ядре этого порта. Пока он выбран, лаунчер показывает плашку на всё окно: **это ранняя версия — возможны артефакты, вылеты и просадки FPS, ничего не обещаем.** Если что-то не так, вернитесь на рендер v2 (он по-прежнему по умолчанию).
  - На Ryzen 7 5700X + RTX 4070 SUPER в 1080p: 35–45 FPS на улицах (как v2), 60–100 наверху — частота кадров больше не привязана к ступеням 60 Гц; ограничение FPS и VSync из лаунчера работают.
  - Статтеров намного меньше, чем в первых сборках: большие рывки по 50–100 мс (тысячи обращений к защищённой памяти за кадр в частицах и подгрузке файлов) убраны.
  - При первом запуске игра готовит шейдеры (около двух минут) с экраном прогресса, как в v2; при следующих запусках этот шаг пропускается.
  - Пока нет: FSR 1 / RCAS к нему не применяются, работает только в Windows.
- **Исправлено: окно лаунчера выходило за край экрана** на небольших экранах и при большом масштабе Windows (портативные ПК вроде OneXPlayer X1 с масштабом 200%): настройки в правом нижнем углу не было видно. Теперь лаунчер подгоняет окно под экран и ставит его по центру.
- **Шрифты лаунчера:** Open Sans и иконки Fluent UI System Icons там, где нет Segoe UI.
