# v0.3.5

## What's new

- **Faster first start on renderer v3** ([#3](https://github.com/VantageEX/infamous-first-light-pc/issues/3)). Preparing the game's shaders took up to 18–24 minutes on a fresh graphics driver cache: v3 built its ~17,000 compute pipelines one at a time. They now compile in parallel on 12 threads behind the same progress screen — a few minutes instead. If a driver compile ever hangs, the game starts after two minutes without progress instead of waiting forever.
- **New: render resolution** (launcher → Display → Render resolution): 1080p (the game's own), **800p for Steam Deck** (1424×800) or **720p for weaker graphics cards** (1280×720). The game renders at that size and the picture is scaled to the window; the HUD keeps its layout. It helps when the graphics card is the limit (the Steam Deck, older cards); on a PC limited by the CPU it changes little. Works on all three renderers.
- **Fixed: no mouse cursor in the in-game menu on renderer v2** ([#4](https://github.com/VantageEX/infamous-first-light-pc/issues/4)) — the menu (Insert) opened without its cursor.
- **The launcher's report now names the graphics card and driver on renderer v3.**

# v0.3.5

## Что нового

- **Быстрый первый запуск на рендере v3** ([#3](https://github.com/VantageEX/infamous-first-light-pc/issues/3)). Подготовка шейдеров занимала до 18–24 минут на «чистом» кэше драйвера видеокарты: v3 собирал свои ~17 000 вычислительных конвейеров по одному. Теперь они собираются параллельно в 12 потоков за тем же экраном прогресса — несколько минут вместо этого. Если сборка в драйвере когда-нибудь зависнет, игра запустится после двух минут без прогресса, а не будет ждать вечно.
- **Новое: разрешение рендера** (лаунчер → Экран → Разрешение рендера): 1080p (как в игре), **800p для Steam Deck** (1424×800) или **720p для слабых видеокарт** (1280×720). Игра рисует в этом размере, а картинка растягивается до окна; интерфейс сохраняет свою разметку. Помогает, когда упор в видеокарту (Steam Deck, старые видеокарты); на ПК, где упор в процессор, меняет немного. Работает на всех трёх рендерах.
- **Исправлено: нет курсора мыши во внутриигровом меню на рендере v2** ([#4](https://github.com/VantageEX/infamous-first-light-pc/issues/4)) — меню (Insert) открывалось без курсора.
- **Отчёт лаунчера теперь показывает видеокарту и драйвер на рендере v3.**
