# v0.3.0 — fewer stutters

> **You need your own copy of the game**, dumped from your own PS4 (CUSA00897, base game 1.00 is the tested one). This download has no game files.

## What's new

- **Far fewer stutters in the first sessions.** On the first start the port reads your game files (about 40 s, shown in the launcher) and compiles the game's graphics pipelines before it starts (about 30 s on renderer v2). Before, they compiled while you played. In testing, waits for new pipelines went from about 19 ms each to under 1 ms.
- The core now applies First Light's own settings by itself, also when it is started without the launcher, and only to First Light.
- If the launcher sits in a folder it cannot write to (such as Program Files), saves, settings and logs go to `%LOCALAPPDATA%\inFAMOUS First Light PC`.
- Reports hide the install and data folders too, not just your user folder and game folder.
- Fixed: "Apply and restart" in the in-game menu could open a second launcher instead of restarting the game.
- Fixed: log lines and Cyrillic letters could be cut in the launcher's log.

## Updating

Unzip into a new folder and copy the `data` folder from the old version next to the new **inFAMOUS First Light.exe** to keep your saves and settings. The first start after updating takes 1–3 minutes longer, once.

## How to play

1. Unzip `inFAMOUS-First-Light-PC-v0.3.0.zip` anywhere (not in Program Files).
2. Start **inFAMOUS First Light.exe** and pick your game folder (the one with `eboot.bin` and `sce_sys`).
3. Press **Play**. F10 shows the FPS overlay, Insert (or R3 + L2) opens the in-game menu.

Windows 10/11 64-bit, a Vulkan 1.3 GPU and a CPU with AVX are needed. If Windows SmartScreen warns about an unknown app, choose *More info → Run anyway* (the build is not signed).

## Known issues

- The classic (fallback) renderer flashes yellow for a moment while a save loads, and its first start takes about 3 minutes. Renderer v2, the default, has neither.
- Reading GPU data back still costs frame rate (work in progress).
- Some lights pulse in the boat cutscene.
- If the game freezes, wait about 15 s before closing it, then send the report: the log now records what the game was waiting for.

Feedback is welcome in the [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): your CPU, GPU, FPS and what you saw.

# v0.3.0 — меньше подлагиваний

> **Нужна ваша собственная копия игры**, снятая с вашей PS4 (проверена CUSA00897, базовая версия 1.00). В архиве нет файлов игры.

## Что нового

- **Намного меньше подлагиваний в первых сессиях.** При первом запуске порт читает файлы вашей игры (около 40 секунд, прогресс виден в лаунчере) и заранее компилирует графические пайплайны игры (около 30 секунд на рендере v2). Раньше они компилировались прямо во время игры. В тестах ожидание каждого нового пайплайна сократилось примерно с 19 мс до менее чем 1 мс.
- Ядро теперь само применяет настройки First Light, даже если запустить его без лаунчера, и только для First Light.
- Если лаунчер лежит в папке, куда нельзя писать (например, Program Files), сохранения, настройки и журналы пишутся в `%LOCALAPPDATA%\inFAMOUS First Light PC`.
- Отчёты прячут ещё и папку установки и папку данных, а не только папку пользователя и игры.
- Исправлено: «Применить и перезапустить» в меню игры могло открыть второй лаунчер вместо перезапуска игры.
- Исправлено: строки и русские буквы в журнале лаунчера могли обрываться.

## Обновление

Распакуйте в новую папку и скопируйте папку `data` из старой версии рядом с новым **inFAMOUS First Light.exe**, чтобы сохранить сейвы и настройки. Первый запуск после обновления один раз займёт на 1–3 минуты дольше.

## Как играть

1. Распакуйте `inFAMOUS-First-Light-PC-v0.3.0.zip` куда угодно (не в Program Files).
2. Запустите **inFAMOUS First Light.exe** и выберите папку с игрой (в ней `eboot.bin` и `sce_sys`).
3. Нажмите **«Играть»**. F10 — счётчик FPS, Insert (или R3 + L2) — меню в игре.

Нужны Windows 10/11 64-бит, видеокарта с Vulkan 1.3 и процессор с AVX. Если Windows SmartScreen предупредит о неизвестном приложении, нажмите *«Подробнее» → «Выполнить в любом случае»* (сборка не подписана).

## Известные проблемы

- На обычном (запасном) рендере при загрузке сохранения на мгновение мелькает жёлтый, а первый запуск занимает около 3 минут. На рендере v2, который стоит по умолчанию, такого нет.
- Чтение данных с видеокарты всё ещё стоит FPS (в работе).
- В катсцене с лодкой мигают некоторые огни.
- Если игра зависнет, подождите секунд 15, прежде чем закрывать, и пришлите отчёт: в журнале теперь записывается, чего ждала игра.

Отзывы ждём в [Issues](https://github.com/VantageEX/infamous-first-light-pc/issues/new/choose): ваш процессор, видеокарта, FPS и что вы увидели.
