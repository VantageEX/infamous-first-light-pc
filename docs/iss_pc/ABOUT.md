# iss_pc documentation

This folder keeps the documentation of [iss_pc](https://github.com/HayatoG/iss_pc), HayatoG's
native PC port of inFAMOUS Second Son, which this project's core (`port/`) comes from. It
describes that port (its launcher, its packages, Second Son's dump), not this one, and is kept
for the core's background and for credit. Links inside may point to files this fork removed.
