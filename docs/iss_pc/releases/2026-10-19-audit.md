# Auditoria da próxima release — 19/10/2026

Base: `v2026.10.18-27f8bba` (`27f8bba8cb0df06c1aa316a8e131db90c108e04a`). Corte: `ea8b86e439c79ac2fdb59df95c81ea4c8cc624fd`.

A publicação manual [39208783505](https://github.com/HayatoG/iss_pc/actions/runs/39208783505) falhou no Linux; Windows passou. O job de publicação foi ignorado e nenhuma nova release saiu. Uma reexecução desse run continua usando o SHA antigo: é necessário iniciar uma nova publicação após mesclar as correções.

Falhas verificadas:

- C: GCC 14 acusa possível uso de `instance` sem inicialização em `test_mp3.c`.
- Python: dois testes herdados do GoW3 importam `tlg_launcher_win` e `tlg_assets`, módulos ausentes neste port. Removê-los não elimina cobertura de uma implementação existente: eles testam APIs do port original que este repositório não tem. Os controles de stream memory deste port continuam cobertos pelos testes atuais de opções avançadas.
- GPU: `test_readback_sources.cpp` ignora o retorno de `fread`, rejeitado por `-Werror` com os headers protegidos do Ubuntu.
- Após essas correções, o primeiro CI do #305 passou Python e GPU, mas revelou `SIGSEGV` no teste SSE4A. Os auxiliares em assembly dos testes SSE4A/F16C capturavam a flag DF do guest e retornavam ao C com DF ligado, violando a ABI. `cld` depois da captura preserva a comparação de registradores e restaura a ABI do host. Reproduzido localmente com `-mstringop-strategy=rep_byte`: antes exit 139; depois SSE4A nativo e modelo sem SSE4A passam; F16C passa com 78.868.960 comparações. O crash no CI é real, não um travamento do Actions.
- Notas: instruções longas vêm antes do changelog; o parser mistura idiomas no #231 porque não reconhece os fechamentos `<!-- /notes:pt-BR -->`; o #281 gera um bullet vazio; só a última linha de cada PR recebia a referência; a comparação não tinha paginação e erros intermediários de API podiam deixar notas incompletas.

Correções: notas no topo, parser que reconhece fronteiras de idioma e ignora bullets vazios, referência em cada bullet, comparação paginada, falha imediata na consulta de commits/PRs, inicialização explícita do teste MP3, conferência do retorno de leitura no teste GPU e remoção dos testes de módulos ausentes. Não muda o runtime do jogo. Os auxiliares SSE4A/F16C também limpam DF antes de voltar ao C. As etapas de build mostram progresso periódico enquanto o Ninja escreve seu log.

As notas editoriais bilíngues estão em [2026-10-19-preview.md](2026-10-19-preview.md). O corte contém 16 PRs e 97 commits; incluir também este PR de correção e qualquer merge posterior quando o SHA final estiver definido. O changelog gerado pelo workflow usa o SHA real do build. Só editar a mensagem de uma release depois de confirmar que ela existe e que sua tag corresponde ao pacote publicado; preservar as instruções e assets existentes.
