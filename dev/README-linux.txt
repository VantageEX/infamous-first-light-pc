inFAMOUS First Light PC — Linux / Steam Deck
============================================

You need your own copy of the game (a CUSA00897 dump). No game file comes with this package.

Steam Deck
----------
1. Switch to Desktop Mode (Steam button → Power → Switch to Desktop).
2. Unpack this archive somewhere in your home folder, e.g. ~/Games/
   (right-click → Extract, or: tar -xzf inFAMOUS-First-Light-PC-linux-x86_64.tar.gz).
3. Copy your game dump to the Deck or an SD card.
4. Start "inFAMOUS First Light" (double-click), pick the game folder, press PLAY.
5. For Game Mode: in Steam, Games → Add a Non-Steam Game → Browse… → choose
   "inFAMOUS First Light" from the unpacked folder. Then launch it from Game Mode.

The launcher updates itself when a new release is out (the same as on Windows); your settings,
logs and saves stay in the data/ folder beside it.

Other Linux PCs
---------------
x86-64 with glibc 2.39 or newer (Ubuntu 24.04, Fedora 40, Arch, SteamOS 3.6 or newer) and a
Vulkan driver (Mesa RADV for AMD, the NVIDIA driver). Unpack and start "inFAMOUS First Light".

Problems: Log → Create report in the launcher, and send the zip.

inFAMOUS First Light PC — Linux / Steam Deck
============================================

Нужна ваша собственная копия игры (дамп CUSA00897). Файлов игры в этом архиве нет.

Steam Deck
----------
1. Перейдите в режим рабочего стола (кнопка Steam → Питание → Переключиться на рабочий стол).
2. Распакуйте архив в домашнюю папку, например в ~/Games/
   (правый клик → Извлечь, или: tar -xzf inFAMOUS-First-Light-PC-linux-x86_64.tar.gz).
3. Скопируйте дамп игры на Deck или SD-карту.
4. Запустите «inFAMOUS First Light» (двойной щелчок), выберите папку с игрой, нажмите «ИГРАТЬ».
5. Для игрового режима: в Steam — Игры → Добавить стороннюю игру → Обзор… → выберите
   «inFAMOUS First Light» в распакованной папке. После этого запускайте из игрового режима.

Лаунчер сам обновляется, когда выходит новый релиз (как и на Windows); настройки, логи и
сохранения остаются в папке data/ рядом с ним.

Другие ПК с Linux
-----------------
x86-64, glibc 2.39 или новее (Ubuntu 24.04, Fedora 40, Arch, SteamOS 3.6 и новее) и драйвер
Vulkan (Mesa RADV для AMD, драйвер NVIDIA). Распакуйте и запустите «inFAMOUS First Light».

Проблемы: в лаунчере «Журнал» → «Собрать отчёт», и пришлите zip.
